## 取消改动的原因

Redis 跨槽补丁不属于简单改名。本地用户缓存 Lua 还原子检查钱包提交不确定围栏及任务账本围栏，Token 缓存同样有任务账本状态。只换上游涉及的 key 仍会跨槽；将持久围栏一并换名又会让新节点看不到旧节点遗留的不确定扣款。此次保持现有名称与拒绝重放约束，不宣称支持 Redis Cluster。

易支付当前在验签之外还强制主动查单，覆盖充值、订阅和补单。上游 RSA 补丁主要改变下单与验签，直接使用会让 RSA 网关仍走旧 MD5 查询接口。旧订单又没有签名模式/商户配置快照，切换全局配置可能使旧回调失效。取消这项不表示观察到数据库丢行，而是无法在本次独立补丁范围安全兼容完整支付链。

`f3d8b737b` 的零复制 JSON、ojson 扫描及构建链依赖此前已取消的 `70e6af642`。它改变请求体所有权、重复 JSON 成员、参数覆盖、计费读取和独立 relaykit 合同。只移植可与引擎拆分的修复，保留现有标准 JSON 与 gjson/sjson；无插件运行时或依赖进入产物。
