# v0.5.14 发布前审查与验收

日期：2026-11-15。发布基线为 `v0.5.13` / `c3219e329a94d437b00c3c04ee9bd4798cc2f398`，应用修复提交为 `01df1f207`。先前前端修复已重新基于最新主分支整理，保留 v0.5.13 已包含的后端与依赖变更。本次不部署生产服务。

## 审查范围

对本次全部应用变更及相关调用链分组交叉审查，覆盖 HTTP 与认证刷新、用户额度和编辑器、Playground 存储和历史、共享输入和可访问性、响应式布局、语言启动和复制、密钥预设与时间运算。另行检查后端接口语义、跨模块回归、依赖审计、CI 和正式发行工作流。这里的完整审查指本次发行变更及关联路径，不代表逐行重新审计仓库所有历史代码。

原始前端报告中的 14 项问题均已处理；第二轮审查补充发现的问题也已修复并增加回归用例。

| 范围           | 最终处理                                                                                                                                                                                                        |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## 发布门禁与数据边界

CI 只监听 PR 和手动触发，普通分支 push 不会启动完整检查。发布顺序为：推送候选分支 → 对最终提交手动触发 CI → 确认全部 10 个作业成功且 SHA 一致 → 快进 `main` 并推送新的 annotated `v0.5.14` 标签 → 等待正式 Release 与多架构 Docker 工作流。

发布工作流检查标签与事件提交一致，先在 draft 中收齐 11 个资产，再公开发布。发布后核对 7 个可执行文件与 4 份校验文件、构建证明、镜像 amd64/arm64、版本与源提交，以及稳定版标签与 `latest`。最终远端 CI 和发布结果以对应提交及标签的 GitHub Actions 记录为准，不把本地构建当成正式发行产物。

此修复不能恢复旧版本已经覆盖的对话。存储不足时应使用完整 JSON 导出；离页提示仍受浏览器能力限制，强制退出或账户切换仍可能丢失未保存的内存内容；上一账户的对话不会暴露给下一账户。请求取消不能撤销服务器已经完成的操作，也不能撤回浏览器已经接收的 `Set-Cookie`。升级继续保留数据库、数据卷、会话和加密密钥。
