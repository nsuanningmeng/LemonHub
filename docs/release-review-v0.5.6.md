# v0.5.6 发布前独立审查与验收

日期：2026-10-24（北京时间）。审查范围为上次正式版 `v0.5.5` / `0fb01c80b` 之后的全部变更，包含先前快进保留的本仓库性能统计改动，以及选择性移植的上游 30 个提交。本阶段在用户明确要求“全面审查，通过后 push、发 release”后进行；发布不包含生产部署。

## 审查覆盖与修复

由独立审查者分别检查计费全链、转发与协议转换、前端、数据库/性能统计/限流、发布工作流，主代理再复核修复 diff。检查覆盖权限、缓存失效、请求克隆、错误与重试、钱包/Token/订阅退款、任务 CAS、JSON 兼容及构建身份，不只复用上一轮结论。

| 范围 | 新发现与最终处理 |
| --- | --- |
| Claude 工具转换 | 缺少 function 参数的 `type=custom` 工具原本会被忽略，新 schema 标准化却把它变成空名称函数。恢复非函数工具过滤，保留合法 function 省略 schema 的行为，并覆盖混合工具请求。 |
| 派生缓存倍率 | 合法 JSON 浮点 `9e307` 乘 2 后成为 `+Inf`，可在没有缓存用量时也触发 decimal panic。在发送前拒绝非有限派生倍率；旧/直接快照按 decimal 运算防御并沿用额度饱和。 |
| 审计元数据 | 既有 `QuotaClamp.AuditMap` 直接写 NaN/Inf，JSON 无法编码时会丢失整份日志 Other。仅非有限 original 改用可读字符串；有限值仍为数字，真实结算与日志回归通过。 |
| Web 依赖 | 原审计 14 条公告，最小升级 DOMPurify 3.4.17、Zod 4.6.6、follow-redirects 1.16.1、Undici 7.30.1、Vite 8.1.6；保留既有安全覆盖。Vite 显式开发依赖保证 peer 的实际锁定版本。 |
| Electron 依赖 | Electron 44.9.3 包含不可信中间证书保护；同步 fast-uri 3.1.9 与 Undici 7.30.1/6.29.1，保留 roarr 的限定覆盖。 |
| 数据与权限 | 从 v0.5.5 起复核 UTF-8/GBK 精确身份迁移、认证统计接口、模型/组可见集合缓存、热统计与 SQL 快照、看板事务和 Redis NOSCRIPT，无新增未修复阻断。 |

实验插件系统仍未引入。先前取消的动态流写入预算、汇率批量调价仍不合并，原因见[逐提交处置](upstream-sync-2026-10-23.md)。

## 缓存计费兼容性

不回写历史账单，不自动覆盖已保存的价格/表达式。之后携带缓存用量的请求可能增加费用：此前遗漏的 Claude 缓存会参与结算；未独立设置的 1h/12h 写入分别按短期价的 1.6/2 倍回退，短期价格也不存在时归入输入价。显式零价保持零价；真实上下文 `len` 不加权。

下列来自回归用例的数字是表达式原始结果，不是统一涨价比例，最终扣额仍按站点表达式版本、分组倍率和额度单位换算：

| 请求和原有表达式 | 旧结果 | 新结果 |
| --- | ---: | ---: |
| Claude：`p`，新鲜输入 100、缓存读 200、缓存写 300（含 1h 100） | 100 | 660 = 100 + 200 + 200 + 100×1.6 |
| OpenAI：`p + cr*0.1 + cc*1.25`，总输入 1000、缓存读 100、缓存写 300（含 12h 200） | 985 | 1235 = 600 + 10 + (100 + 200×2)×1.25 |

无缓存请求不因这个计费修正增加费用；无效的极端价格配置改为提前失败。新预设只在主动选择时应用。

## 发布与生产边界

既有 CI 仅监听 PR 和手动触发，普通分支 push 不自动运行它。因此发布次序为：本地审查与验证通过 → 推送审查分支 → 对准确提交触发并等待 CI → 快进主分支并推送新的 annotated tag → 等待完整 Release 和双架构镜像工作流完成。标签不能移动，最终远端 SHA 必须与被检查的提交一致。

标签工作流从 `.github/release-notes/v0.5.6.md` 读取说明，先收集 Linux/macOS/Windows 和 Electron 的全部资产，再发布 Release。正式 Docker 工作流使用仓库原始多阶段 Dockerfile，构建 amd64/arm64、合并 manifest 并发布签名。不得把本地等效运行时镜像冒充该完整构建结果。

MySQL 8.2 的旧表迁移与数据保留证据不等于约 800 GB、单实例、60 秒中断预算已验收。性能统计身份回填/索引、元数据锁、在途结算排空都可能超过窗口；现有停机期限为 120 秒、Docker 宽限 130 秒。仍需生产只读核查和真实规模克隆演练。本任务不操作生产，不缩短停机期限来绕过待刷新账本。

证据保存在 `/workspace/scratch/upstream-sync-2026-10-23/` 及 `/workspace/scratch/release-v0.5.6-2026-10-24/`；测试凭据、完整 SQL 备份不进入仓库。
